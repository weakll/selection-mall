# 简历项目材料

## 项目名称

精选商城 | Spring Cloud Alibaba 微服务商城

## 项目描述

基于 Spring Cloud Alibaba、Vue 3 和 Docker Compose 构建的前后端分离微服务商城，覆盖用户认证、商品浏览、购物车、优惠券、订单和可演示支付链路。

## 简历亮点

- 使用 Spring Cloud Gateway 统一路由和鉴权，结合 Nacos 完成服务注册发现，拆分用户、商品、购物车、订单和支付服务。
- 在下单链路中使用 Redis 幂等控制、库存原子扣减和事务补偿，处理重复提交、库存不足和订单落库失败等场景。
- 实现优惠券发布、领取、限领和订单核销，使用 MySQL 事务与行级锁维护优惠券库存和领取数量。
- 完成待付款订单取消、库存恢复和支付状态流转，支付通知通过订单号、交易号、金额和状态校验保证幂等。
- 使用 Docker Compose 编排 MySQL、Redis、Nacos、网关、业务服务和 Nginx H5，提供可重复的本地部署环境。

## 截图清单

建议按以下顺序截图：

1. 首页：商品分类、推荐商品和底部导航。
2. 商品详情：价格、规格、库存和立即购买入口。
3. 确认订单：收货地址、商品明细、优惠券和实付款。
4. 我的订单：待付款订单、取消订单和支付入口。
5. 支付完成：订单状态变为已支付或待发货。
6. Docker Desktop：基础设施和应用容器运行状态。

当前支付模块为本地虚拟支付演示链路，简历中应按演示链路描述，不表述为真实第三方资金支付。
