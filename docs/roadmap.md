# Roadmap

## v1：微服务商城

### 阶段一：仓库初始化（已完成）

- 建立 monorepo 结构
- 配置 Git 忽略规则
- 完成架构和开发文档
- 完成本地配置模板

### 阶段二：源码迁移与重命名（已完成）

- 迁移后端源码
- 迁移 H5 源码
- 统一 Maven 坐标和 Java 包名
- 清理旧项目标识、构建产物和密钥

### 阶段三：缓存一致性（已完成）

- 商品详情缓存
- 分类与品牌缓存
- 空值缓存
- 随机 TTL
- 商品变更后的主动失效

### 阶段四：交易一致性（已完成）

- 库存条件扣减
- 库存不足处理
- 订单提交幂等
- 支付回调幂等
- 超时订单关闭与库存回补

### 阶段五：质量与交付（进行中）

- 核心测试
- GitHub Actions
- Docker Compose
- 本地启动说明
- 页面截图（已完成）
- 演示 GIF
- 生产环境部署验证
- Redis 集群场景下缓存失效优化（当前已改为 `SCAN`，跨节点扫描仍需部署验证）
- 库存回补失败后的对账告警

## v2：AI 智能客服（已落地）

- 独立 AI 服务边界（`service-ai`，Boot 3.0.5 同栈，8516 端口）
- 商城客服适配层（`ServiceCenter.vue` 由前端 mock 改为真 SSE）
- SSE 流式响应（实测单次回答 115 个增量，逐字输出）
- 商品查询工具（复用既有商品接口，**未改动商品服务**）
- 当前用户订单查询工具（不接受 userId 参数，隔离在服务端成立）
- 售后政策知识库（`ai/faq-knowledge.yml`，7 条）
- 用户数据隔离（已实现）；**调用限流（待补）**

v2 通过独立服务接入，未在 v1 中预留空模块或空接口。设计与实现说明见
[ai-service.md](ai-service.md)。

### 后续可做
