# Roadmap

## v1：微服务商城

### 阶段一：仓库初始化

- 建立 monorepo 结构
- 配置 Git 忽略规则
- 完成架构和开发文档
- 完成本地配置模板

### 阶段二：源码迁移与重命名

- 迁移后端源码
- 迁移 H5 源码
- 统一 Maven 坐标和 Java 包名
- 清理旧项目标识、构建产物和密钥

### 阶段三：缓存一致性

- 商品详情缓存
- 分类与品牌缓存
- 空值缓存
- 随机 TTL
- 商品变更后的主动失效

### 阶段四：交易一致性

- 库存条件扣减
- 库存不足处理
- 订单提交幂等
- 支付回调幂等
- 超时订单关闭与库存回补

### 阶段五：质量与交付

- 核心测试
- GitHub Actions
- Docker Compose
- 本地启动说明
- 页面截图和演示 GIF

## v2：AI 智能客服

- 独立 AI 服务边界
- 商城客服适配层
- SSE 流式响应
- 商品查询工具
- 当前用户订单查询工具
- 售后政策知识库
- 用户数据隔离和调用限流

v2 默认通过独立服务接入，不在 v1 中预留空模块或空接口。
